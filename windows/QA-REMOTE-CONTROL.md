# JARVIS — дистанційна миша й клавіатура Windows з Pixel

**Стан:** реалізовано в коді; випуски APK/EXE не створювалися. Поки не перевірено на реальному комп'ютері/Pixel. Джерело зберігається в GitHub.

## Як починається керування
1. На Windows запусти оновлений JARVIS, налаштуй приватний HTTPS Cloudflare Worker. У Налаштуваннях увімкни окремо: **Зв'язок пристроїв**, **Перегляд екрана**, **Дозволяти запити на мишу й клавіатуру**.
2. На Pixel відкрий JARVIS, скажи «Покажи екран комп'ютера» або відкрий перегляд кнопкою.
3. На Pixel натисни **«🖱 Попросити керування»**.
4. JARVIS на **самому Windows-комп'ютері** показує запит від Pixel з кнопками **Дозволити / Відхилити**. Без явного натискання «Дозволити» Windows не виконує жодної дистанційної дії.
5. Після підтвердження Pixel отримує право надсилати дотики та клавіші в цій сесії. Внизу є кнопка **⌨ Клавіатура**, яка відкриває додаткові інструменти, не закриваючи весь робочий стіл.

## Дії на Pixel → Windows
- **Один дотик на іконці** — один лівий клік у відповідному місці головного монітора.
- **Два дотики** — подвійний лівий клік.
- **Довге натискання** — правий клік і контекстне меню Windows.
- **Провести одним пальцем** — затиснути, перетягнути та відпустити об'єкт.
- **Прокрутити двома пальцями** або кнопками ↑/↓ — прокрутити сторінку на ПК.
- **⌨ Клавіатура → Введи текст для ПК → Написати** — ввести до 160 символів у поле, попередньо активоване на Windows.
- Окремі клавіші: Enter, Esc, Tab, Backspace, Delete, ↑, ↓, ←, →, Ctrl+A, Ctrl+C, Ctrl+V, PageUp, PageDown.

Координати нормалізуються до фактично видимого зображення Windows. Чорні відступи від різних пропорцій монітора й телефону не викликають кліків. Керування не приймає дії, якщо кадр екрана застарів.

## Зупинка й безпека
- На Pixel: **■ Завершити керування, залишити перегляд** у меню клавіатури або **■ Завершити** для повного виходу.
- На Windows: **■ Заборонити керування** зберігає режим перегляду, а **■ Зупинити екран** припиняє також передавання зображень.
- Дозвіл на дистанційну мишу/клавіатуру вимкнений за замовчуванням. **Кожен новий сеанс** потребує дозволу на Windows.
- Клацання та клавіші потрапляють у короткочасну (непостійну) чергу Cloudflare, не в AI чи файли. Прострочені команди відхиляються, повторна доставка не повинна виконувати клік вдруге.
- Авторизація використовує **спільний особистий JARVIS_CLIENT_TOKEN** через HTTPS. Це поки не попристроєве підтвердження чи E2E-шифрування. **Не вводь паролі, PIN, банківські реквізити чи інші секрети через дистанційне введення.**
- Не працює на захищеному екрані входу в Windows або UAC. Windows може заборонити введення в програми з вищим рівнем привілеїв.
- Вебкамера, мікрофон, системний звук та файли не передаються. Керування можливе тільки за відкритого й дозволеного Windows JARVIS.
- Поточний потік — JPEG-кадри приблизно щосекунди, **не плавний 30/60 FPS відеозв'язок**. Кліки можуть візуально підтверджуватися із затримкою. Для швидшого повноцінного робочого стола потрібне окреме WebRTC-впровадження.

## Чекліст перевірки на пристроях
- [ ] Без дозволу «Перегляд екрана» нічого не показується.
- [ ] Без дозволу «Запити на керування» Pixel не може керувати.
- [ ] Дозволений перегляд без натискання Windows «Дозволити» лишається **тільки переглядом**.
- [ ] Windows показує запит керування й після «Відхилити» не отримує жодного кліку.
- [ ] Windows «Дозволити» запускає управління тільки поточним відкритим Pixel-сеансом.
- [ ] Торкнутися іконки Блокнота — вона відкривається на Windows.
- [ ] Двічі торкнутися іконки Провідника — спрацював подвійний клік, не три окремих.
- [ ] Довго натиснути на порожню область робочого стола — з'явилося контекстне меню.
- [ ] Перетягнути іконку мишею; перевірити, що кнопка миші не лишається затиснутою.
- [ ] Відкрити пошук Windows і ввести з Pixel український текст.
- [ ] Перевірити Enter, Esc, Backspace, стрілки та Ctrl+A/C/V.
- [ ] Прокрутити браузер двома пальцями; чорні поля від зображення не створюють кліків.
- [ ] Перевернути телефон горизонтально — панелі не перекривають панель завдань Windows.
- [ ] Під час передачі вимкнути Wi-Fi: старий кадр не вважається живим, дії не повинні виконуватися пізніше.
- [ ] На Windows натиснути «Заборонити керування»: наступні натискання Pixel не виконуються; зображення може залишитися.
- [ ] На Pixel завершити перегляд: через 8 секунд сеанс має стати недоступним.
- [ ] Після нового підключення керування знову потребує підтвердження Windows.
- [ ] Перевірити, що JARVIS Finance, Spotify на Pixel/Watch7 і голосове керування залишилися без регресій.

## Автоматизовані тести (без збірки)

- `JarvisRemoteTouchMapperTest.java`: FIT_CENTER, точність координат, заборона натискань у чорних полях.
- `.github/workflows/jarvis-screen-source-contracts.yml`: Windows/Android/Cloudflare статичні перевірки без EXE або APK.
- Реальна робота Microsoft SendInput, UI Toolkit Android і затримки перевіряються тільки на комп'ютері та телефоні після окремо дозволених встановлень.

**Важливо:** Cloudflare Worker не розгортається автоматично; це потрібно робити окремо. Не вважати цей модуль завершеним для щоденного використання до фізичних тестів.

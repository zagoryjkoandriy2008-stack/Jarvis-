## Модулі Windows-компаньйона (код у гілці `feature/windows-companion-extensions-20261122`, без збірок)

- **Моніторинг ПК:** «стан комп'ютера», «статус пк» — одноразове читання CPU, RAM та вільного місця системного диска. З Pixel/Watch7 після вибору режиму ПК надходить фактичний текст звіту через Relay. Значення температур GPU/CPU не вигадуються і наразі не доступні.
- **ШІ бачить екран на вимогу:** локальні «проаналізуй екран», «що зараз на екрані» або кнопка «👁 Аналіз екрана» відкривають щоразу підтвердження на Windows. Тільки натискання «Так» захоплює JPEG основного монітора (до 220 КБ, лише в пам'яті) та надсилає його як вкладення до приватного Cloudflare Worker `/chat` у режимі `analysis`. Після запиту локальний JPEG не зберігається у файли. Вміст надсилається сторонній AI-службі, тому закрий чутливі вікна перед підтвердженням. Голосові запити з Watch7/Pixel НЕ можуть обійти локальне підтвердження або автоматично натискати елементи Windows за відповіддю ШІ.
- **Базові макроси:** власні тригери, дозволені дії, а також «пауза 2 секунди» (1–10 секунд, не більше восьми кроків). Попередньо налаштований власником макрос можна викликати з Watch7/Pixel через Relay; довільний shell-код, небезпечні команди, введення тексту і AI-generated кроки заборонені.
- **Двосторонні файли:** Windows → Pixel і Pixel → Windows через приватний Cloudflare Relay. На Windows вкладка «Обмін файлами», на Pixel кнопка «📂 Файли ПК» всередині перегляду Windows. Кожне відправлення потребує ручного вибору файлу, кожне збереження — системного вибору місця. Максимум **1 МіБ на файл**, один файл на напрямок, максимум 120 секунд у RAM Durable Object. Якщо об'єкт Cloudflare вивантажився з пам'яті, тимчасовий файл може зникнути раніше. **Немає наскрізного шифрування, перевірки шкідливих файлів, великих відео, автоматичного запуску чи синхронізації папок.** Не пересилай секрети.
- **Вже існували раніше:** перегляд екрана Pixel ~1 кадр/сек, локально підтверджена дистанційна миша й клавіатура, голосове керування Windows та маршрутизація трьох пристроїв. Ці функції збережені, не замінені новими додатками.
- **Деплой:** Relay-функції потребують розгортання оновленого Worker; Android/Windows-код потребує майбутніх інсталяційних збірок за окремою командою. Зміна GitHub-коду сама по собі **не** оновлює телефон, годинник чи комп'ютер. Дотепер не підтверджено сценарії на фізичних Pixel 9, Watch7 або ПК.

### Обов'язкові ручні перевірки
Дивись [QA-WINDOWS-COMPANION-EXTENSIONS.md](QA-WINDOWS-COMPANION-EXTENSIONS.md). GitHub виконує статичні контракти та Node-тести без інсталяційних пакетів; збірка EXE/APK тільки за прямою командою.

# JARVIS Windows — нативний застосунок (0.2.0 Preview · плаваючий JARVIS + пристрої)

Розробка Windows-версії JARVIS на базі репозиторію Android. Це **перший працюючий етап**, а НЕ повна функціональна еквівалентність Pixel/Watch7.

## Що реалізовано в коді
- Нативний темний WPF-інтерфейс Windows 10/11 (x64): Асистент, JARVIS Finance, Макроси, Нотатки, Налаштування.
- Текстові команди українською/російською, голосове введення натисканням кнопки або **Ctrl+Shift+J** та озвучення через системні Windows-голоси.
- Безкоштовний офлайн-розпізнавач **лише за наявності встановленого SAPI мовного пакета** відповідної мови. Не всі версії Windows містять український мовний розпізнавач.
- Підключення до **того самого** Cloudflare Worker `POST /chat` (режими chat/web/analysis/image; наразі у Windows відповіді відображаються як текст). OpenAI API key у Windows НЕ зберігається; лише довгий окремий Worker-код, захищений поточним обліковим записом Windows (DPAPI).
- Команди Windows: дозволені програми (Блокнот, Калькулятор, Провідник, браузер, Spotify, Telegram), вебпошук, відкриття пошуку Spotify, гучність 0–100%, медіаклавіші, таймер, озвучення та нотатки. Фінанси через Pixel, якщо зв'язок активований.
- Базові макроси: власна точна голосова команда, 1–8 дозволених дій без довільного shell-коду та без рекурсії.
- Локальні параметри й нотатки Windows: `%LOCALAPPDATA%\\Jarvis.Windows\\state.json`; Worker-токен у `worker-token.dpapi`. Старі локальні записи Finance із Preview зберігаються **тільки для перегляду**. Нові голосові записи і звіти спрямовуються на Pixel через приватний Relay, який зберігає фінансову базу в SQLCipher Android.

## Як запустити
1. Відкрий успішний GitHub Actions workflow **JARVIS Windows (portable desktop prototype)**.
2. Скачай artifact `Jarvis-Windows-0.2.0-preview-win-x64`, розпакуй ZIP.
3. На Windows 10/11 x64 запусти `Jarvis.Windows.exe` (може знадобитися підтвердження SmartScreen, бо тестова збірка **не підписана сертифікатом**). Не відключай Windows Defender.
4. У вкладці «Налаштування» додай той самий HTTPS `.../chat` Worker і **особистий токен Worker**, а не OpenAI API key.
5. Вибери доступний системний голос і мову розпізнавання; спробуй «Відкрий блокнот», «Гучність 70», «Таймер 30 секунд», «Витратив 150 готівка транспорт автобус».

## Нове у коді: перегляд Windows на Pixel (без збірки)

- На Pixel: «**Покажи екран комп'ютера**» або кнопка «🖥 Побачити екран комп'ютера».
- На Windows: **окремо ввімкнути** «Дозволити Pixel переглядати мій екран» та «Дозволити з'єднання з Pixel і Watch7». Трансляція працює лише коли Pixel активно переглядає екран.
- На Windows та плаваючому JARVIS з'являється **🔴 індикатор передачі** й кнопка зупинки.
- Через Cloudflare HTTPS надходять **JPEG-кадри головного монітора приблизно раз на секунду**; це базовий перегляд, не відео 30 fps і не дистанційне керування.
- Не зберігає кадри у файли чи AI; припиняє передавання після виходу з перегляду; видаляє останній кадр після відкликання дозволу.
- Для роботи треба вручну розгорнути оновлений Cloudflare Worker і встановити **наступну** Android/Windows збірку, коли власник окремо попросить її створити. **Нині жодного інсталяційного файла з цією функцією немає.**
- Чекліст і обмеження: [QA-REMOTE-SCREEN.md](QA-REMOTE-SCREEN.md).

**Правило збірок:** GitHub Actions із EXE/ZIP запускається **тільки вручну**, не після кожного редагування Windows-коду.

## Нове у коді: дистанційна миша й клавіатура Pixel → Windows

Тепер у перегляді екрана можна **керувати Windows дотиками** після окремого підтвердження **на самому комп'ютері**.

- Windows JARVIS → Налаштування: **дозволити зв'язок**, **дозволити перегляд екрана**, **дозволяти запити на мишу й клавіатуру**. За замовчуванням усі дистанційні дозволи **вимкнені**.
- Pixel JARVIS → «Покажи екран комп'ютера» → «🖱 Попросити керування».
- На Windows з'являються **Дозволити / Відхилити**. Поки власник **не натисне Дозволити**, жодного дистанційного кліку або клавіші.
- Натискання на іконки — лівий клік; два дотики — подвійний; довге натискання — правий клік; перетягування — миша з утриманням; двопальцевий жест — прокручування.
- Через кнопку **⌨ Клавіатура** доступні український/російський текст (до 160 символів), Enter, Esc, Tab, Backspace, стрілки, Ctrl+A/C/V та сторінкове прокручування.
- Windows показує **🔴 Pixel керує мишею і клавіатурою** й кнопку **■ Заборонити керування**. Окремо можна зупинити весь перегляд.
- Однаковий Worker-токен і HTTPS, **без наскрізного шифрування та повноцінного попристроєвого pairing**. Не використовувати дистанційне введення для паролів та чутливих даних.
- Керування не працює на захищених екранах Windows/UAC, тільки за активного сеансу JARVIS, і поки це приблизно один JPEG-кадр/с, а не плавний WebRTC.

Детально: [QA-REMOTE-CONTROL.md](QA-REMOTE-CONTROL.md).

**Ці зміни лише у вихідному коді — Windows EXE та Android APK не створювалися, повний тест на фізичних пристроях попереду.**

## Керування екраном Windows (локальний режим)

З JARVIS Windows 0.2 Preview реалізовано початкове **керування елементами активного вікна**, без крихких координатних натискань:

- `комп'ютер` → `натисни кнопку Пошук` — знаходить елемент із доступною назвою «Пошук» у **поточному вікні іншої програми** через Microsoft UI Automation.
- `натисни на кнопку Відтворити` — натискає доступний елемент «Відтворити», якщо він є.
- `прокрути вниз`, `свайпни вгору` — PageDown/PageUp в активному вікні.
- Плаваючий JARVIS не повинен перехоплювати активне вікно після натискання кнопки мікрофона, щоб не втратити потрібний застосунок.
- Кнопки, що не мають доступної назви в Windows UI Automation, не будуть натиснуті; JARVIS повідомить про це.
- **Важливо:** команди `натисни`, `свайпни` залишаються **лише локальними на Windows**. Вони не дозволені через Cloudflare Relay з Pixel/Watch7, щоб не було непомітного натискання небезпечних кнопок.
- Команда `напиши текст` в інше активне поле залишається окремою локальною операцією, але працює лише за умови, що у фокусі не JARVIS і користувач явно вибрав потрібне поле.

## Спільні нотатки й фінанси

- На вкладці **Нотатки** нові записи з Windows надсилаються на Pixel (перший і єдиний активний журнал). Команди: `запиши нотатку Купити хліб`, `покажи нотатки`, `видали останню нотатку`.
- Раніше створені **локальні нотатки Windows** збережені як архів лише для читання — вони НЕ переносяться автоматично.
- JARVIS Finance: команди з Windows і Watch7 читають/змінюють дані в оригінальній зашифрованій базі **Pixel**, без паралельного створення транзакцій у Windows.
- Relay повертає реальне підтвердження Pixel; якщо мережа втрачена або час вичерпано, результат може бути невідомим. **Не повторюй одразу фінансову команду**, спочатку перевір її в журналі Pixel.
- Windows зберігає короткочасний журнал ідентифікаторів отриманих команд `remote-receipts.json`, щоб не повторювати системні дії після перезапуску. Він не містить повного транскрипту розмови.

## Плаваючий JARVIS і керування трьома пристроями

- Плаваюче 8-бітне обличчя Windows з кнопкою мікрофона, переміщенням по екрану, меню й трьома іконками. З'являється при запуску, можна приховати.
- Голосові перемикачі: **«комп'ютер»** — локальний Windows, **«телефон»** — команди Pixel, **«годинник»** — Watch7 через Pixel. Поточна ціль показана на обличчі та у вкладці **Пристрої**.
- Команди JARVIS Finance з Windows надсилаються Pixel незалежно від вибраної цілі. Якщо Pixel офлайн або Relay не налаштований — команда не записується локально і повертає відмову, щоб уникнути двох різних журналів.
- Керування комп'ютером із Pixel/Watch7: тільки локально дозволені команди (медіа, гучність, відкриття відомих програм, Spotify-пошук, браузер, голос, таймер). Сторонній текст із ШІ не запускає процеси чи кліки.
- Для Cloudflare Relay потрібні: оновлений Worker із Durable Object, той самий URL і токен у Windows/Pixel, окремий опційний дозвіл на обох Android-пристроях та ввімкнена фонова служба Pixel.
- **Реліз APK зі змінами Android не створено.** Працездатність реального каналу в трьох напрямках не підтверджено фізичними пристроями.

Дивись `windows/QA-WINDOWS-0.2.0.md` та `android/QA-JARVIS-DEVICE-RELAY.md`.

## Чого поки немає (не вважати готовим)
- Немає безперервного режиму wake-word 24/7, вибору Bluetooth/мікрофонів, довільного українського STT без системного пакета.
- Spotify на Windows: **відкривається пошуковий URL**; автоматичний вибір першої пісні або Play плейлиста, як на Android, **не реалізовані**. Медіаклавіші працюють через Windows.
- Є базове **локальне** керування доступними іменованими елементами через Windows UI Automation, але воно ще не покриває всі програми, координатні жести, контекстні меню та складні віконні переходи. Команда «напиши» потребує фокусу іншої програми, і її не можна викликати зі звичайного текстового поля JARVIS.
- Немає **офлайн-реплікації** Android-бази Finance або нотаток у Windows та синхронізації макросів; Finance і активні нотатки виконують запити на Pixel через Cloudflare Relay. Для справжнього офлайн-синхронізованого журналу ще потрібні шифрований протокол, конфлікт-резолвер, міграція та сильніша попристроєва авторизація.
- Режим image наразі не відображає створене зображення: сервер повертає його, але Windows Preview використовує лише текстову частину. Немає вкладення файлів у ШІ.
- Немає встановлення будильника в Windows Clock та системних змін Wi-Fi/Bluetooth/авіарежиму. **Режим міжпристроєвого керування реалізовано частково:** лише для дозволених команд, при активному Relay, налаштованому комп'ютері й доступних Pixel/Watch7.
- Фонові таймери працюють тільки поки програма відкрита. Повної перевірки на фізичній Windows-машині ще немає.

## Безпека
- Ніяких паролів, OpenAI API ключів, кліків із відповіді ШІ чи необмежених PowerShell-команд.
- Дані нотаток і фінансів у Windows **поки не зашифровані**; захищений DPAPI лише Worker-токен. Не копіюй файл state.json у публічні місця.
- AI відповіді не виконують системних дій.
- Не змішувати Windows JSON із Android SQLCipher. Керування фінансами з Windows працює як дистанційна команда Pixel; це не копія бази. Cloudflare Relay використовує **той самий** довгий приватний JARVIS_CLIENT_TOKEN, що й /chat; це лише персональний прототип, а не повноцінне розмежування прав між пристроями. Передача — HTTPS; команда може короткочасно перебувати в Durable Object до 2 хвилин, без наскрізного шифрування.

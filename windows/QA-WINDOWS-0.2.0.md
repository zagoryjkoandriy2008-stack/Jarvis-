# JARVIS Windows 0.2.0 Preview — чекліст

## A. Локальний застосунок
- [ ] Розпакуй ZIP із workflow **JARVIS Windows**, запусти **Jarvis.Windows.exe** на Windows 10/11 x64
- [ ] Плаваючий круглий JARVIS з'являється окремо від основного вікна; перетягни його, сховай, знову покажи
- [ ] Клік по обличчю і Ctrl+Shift+J вмикають мікрофон, якщо у Windows є мовний пакет
- [ ] Команди «відкрий блокнот», «гучність 70», «таймер 30 секунд», медіаклавіші відпрацьовують локально
- [ ] «Скажи привіт» озвучується вибраним голосом; закриття застосунку завершує запис мікрофона

## B. Вибір цільового пристрою
- [ ] «Комп'ютер» — внизу орба 🖥; команди виконуються на Windows
- [ ] «Телефон» — 📱; наступні дозволені команди надсилаються тільки Pixel
- [ ] «Годинник» — ⌚; наступні дозволені команди надсилаються Watch7 через Pixel
- [ ] Натискання кожної іконки перемикає ціль без повторного голосового запиту
- [ ] Після зміни цілі фінансові команди все одно спрямовуються до **Pixel**
- [ ] Перемикання не змінює налаштування Android, а без Relay відхиляє команду

## C. Підключення (після окремого розгортання Cloudflare Worker)
- [ ] Cloudflare Worker оновлено; `/chat` працює; Durable Object DeviceRelay створений
- [ ] Один і той самий **особистий Worker URL + довгий JARVIS_CLIENT_TOKEN** налаштовані на Windows і Pixel; токен не вводити в чат
- [ ] У Windows ввімкнено «Дозволити зв'язок із Pixel і Watch7» і збережено
- [ ] На Pixel ввімкнено «Дозволити зв'язок JARVIS» і фонову службу
- [ ] На Watch7 у меню ⋮ дозволено віддалене керування, годинник підключено через Wear
- [ ] Вкладка «Пристрої» правильно показує, хто в мережі (онлайн Relay не гарантує дозволу чи розблокованого екрана)

## D. Команди й фінанси
- [ ] З Windows «телефон» → «увімкни пісню Мама»: Pixel підтверджує дію (не змінювати працюючий Spotify алгоритм)
- [ ] З Windows «годинник» → «увімкни пісню Мама»: Watch7 виконує тільки при видимому JARVIS та активному дозволі
- [ ] З Pixel «комп'ютер» → «гучність 40»: змінилася гучність **Windows**, а не Pixel
- [ ] З Watch7 «комп'ютер» → «відкрий блокнот»: Windows виконав тільки дозволену програму
- [ ] З Windows «витратив 150 готівка транспорт таксі» з'являється **один** запис в SQLCipher базі Pixel
- [ ] З Windows кнопка «Оновити звіт» отримує дані Pixel, а не локальні старі транзакції
- [ ] Вимкни Relay/мережу/Pixel: на Windows немає фальшивого повідомлення про виконання чи дубльованої транзакції
- [ ] Повтори після закриття і запуску Windows: інші команди не відтворюються повторно; фінансові дані не мігрують автоматично

## E. Межі реалізації
- [ ] Зрозуміло, що не всі Android API/Spotify/екранні команди реалізовані на Windows
- [ ] Перевірено, що режим ШІ не виконує інструментів керування пристроями з генерованої відповіді
- [ ] Жодних команд із PIN, паролями, shell-кодом або доступом до заблокованого екрана
- [ ] Відсутність повної синхронізації офлайн-баз, а не приховані повторні локальні записи

**Статус:** код + GitHub Actions тестування; ручне тестування на реальних пристроях не виконано.

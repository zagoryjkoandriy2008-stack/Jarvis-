# JARVIS — перегляд екрана Windows на Pixel

**Стан:** зміни лише у вихідному коді. Автоматичне створення EXE/ZIP із Windows-вихідників відключене; нових APK/EXE для цього функціоналу НЕ зібрано. Не вважати перевіреним на реальних пристроях.

## Робота функції
1. Windows JARVIS відкритий на комп'ютері. У Налаштуваннях збережено приватний HTTPS Cloudflare Worker `/chat` і токен Worker.
2. У Windows ввімкнено **Дозволити з'єднання з Pixel і Watch7** та додаткову опцію **Дозволити Pixel переглядати мій екран**. За замовчуванням другий дозвіл вимкнений.
3. Pixel має той самий Worker, активований зв'язок пристроїв, оновлений JARVIS.
4. На Pixel натиснути **🖥 Побачити екран комп'ютера**, або сказати **«Джарвіс, покажи екран комп'ютера»**.
5. На Pixel відкривається режим **тільки перегляду** головного монітора Windows, JPEG-кадри приблизно 1 раз на секунду. Працює через HTTPS/Cloudflare і мобільний інтернет, не обмежено одним Wi‑Fi.
6. Під час передачі у Windows показується **🔴 Екран транслюється на Pixel**, на плаваючому JARVIS — червона позначка. Кнопка **■ Зупинити екран** або вимкнення дозволу блокує нові кадри і запитує миттєве очищення останнього з Cloudflare.
7. На Pixel натиснути **■ Завершити перегляд** або перейти до іншої програми: сеанс закривається; якщо з'єднання втрачено, за 8 секунд автоматично закінчиться.

## Безпека й технічні обмеження
- Не передає мікрофон чи системний звук; не передає мишку, клавіатуру або кліки. Це **не повноцінний віддалений робочий стіл**.
- Кадри зменшуються приблизно до 960 пікселів по ширині та стискаються JPEG; до 240 КБ на кадр. Це свідомо не WebRTC-відео 30 кадрів/с.
- Кадри зберігаються лише у пам'яті процесу Windows, Android ImageView і активного Cloudflare Durable Object. Не пишуться в локальні файли, R2/KV/DO storage, логи чи ШІ, а старий кадр стає недоступним через 5 секунд або одразу після зупинки/відкликання дозволу.
- Використовується **спільний приватний JARVIS_CLIENT_TOKEN** (той самий що й /chat). Передавання через HTTPS. Немає наскрізного E2E-шифрування між ПК і Pixel, не призначено для багатокористувацького сервісу.
- На Pixel вікно позначене `FLAG_SECURE`: системні скриншоти екрана перегляду блокуються з міркувань приватності.
- Екран Windows може містити паролі та особисті дані. Увімкни дозвіл лише на своєму комп'ютері.
- Працює лише коли ПК ввімкнений, користувач увійшов у Windows, JARVIS Windows відкритий, дозволи ввімкнені й Cloudflare Relay розгорнутий. На екрані входу/захищеному робочому столі Windows захоплення може бути неможливим.
- На першому етапі захоплюється **головний монітор**, не всі монітори одночасно.
- Cloudflare-канал треба **розгорнути окремо вручну**: `server/jarvis-ai-worker/DEVICE-RELAY-SETUP.md`. GitHub commit нічого не розгортає на реальні пристрої.

## Чекліст реальної перевірки
- [ ] На Windows зняти прапорець дозволу: Pixel показує повідомлення, але жоден кадр не надсилається.
- [ ] Увімкнути обидва дозволи Windows, зберегти; на Pixel увімкнути Relay і відкрити перегляд.
- [ ] Побачити робочий стіл Windows на Pixel; пересунути мишку або вікно й перевірити зміну зображення протягом кількох секунд.
- [ ] Перевірити мобільний інтернет Pixel без спільної мережі Wi‑Fi.
- [ ] Перевірити індикатор на Windows і плаваючому JARVIS.
- [ ] Натиснути «Зупинити екран» у Windows: Pixel більше не повинен отримувати нові кадри й має прибрати старий.
- [ ] Закрити перегляд на Pixel: через 8 секунд на Cloudflare сеанс має завершитися.
- [ ] Закрити JARVIS Windows і відкрити Pixel viewer: не повинно з'явитися нове зображення.
- [ ] Перевірити повторне відкриття після зупинки/втрати мережі.
- [ ] Переконатися, що Spotify на Pixel/Watch7 і JARVIS Finance не змінили поведінки.

**Джерела перевірки:** Node.js контрактні тести Cloudflare, Java policy-контракти для голосового виклику на Pixel та окремий статичний Windows/Android/Worker screen-contract workflow. **Після останніх змін Android і Windows застосунки не компілювалися** на вимогу власника; отже реальну роботу Windows GDI-захоплення, перевірку пакета на Pixel та швидкодію на фізичних пристроях ще не підтверджено. Публікація й збірки запускаються лише за окремою командою.

# Дімон 0.1.47 — Galaxy Watch7: апаратний чекліст

> Автоматичні контракти не доводять роботу реальних кнопок Spotify/Maps чи українського TTS в Wear OS. Реальні сценарії потрібно перевірити після встановлення.

- [ ] Оновити попередній встановлений APK поверх, не видаляючи дані, та відкрити Дімона; головний екран — обличчя, застосунок не закривається після команди
- [ ] Натиснути **⋮** угорі праворуч → **🔊 Вибрати голос Watch7**: меню з реально клікабельними пунктами
- [ ] Відкрити **Вибрати голос**: бачити системний Android TTS, усі українські голоси з рушія і кнопку додавання голосів Wear OS; меню не порожнє навіть без укр. пакета
- [ ] Вибрати інший встановлений український голос (якщо є), прослухати; відновити після перезапуску
- [ ] Спробувати **Тембр → нижчий / звичайний / вищий**, прослухати та перевірити збереження
- [ ] Перемкнути **Голосові відповіді** — вимкнути й увімкнути; зробити команду «скажи привіт»
- [ ] Виконати «Увімкни пісню [назва]» у Spotify: пошук, тільки свайп УГОРУ (без вправо), перший результат, звук, потім «Не та пісня» й наступний результат
- [ ] «Увімкни реп» і «Увімкни плейлист [інша збережена назва]» через синхронізовані плейлисти Spotify Remote Pixel; на Watch7 має запускатись відтворення, а не лиш відкриття картки
- [ ] Закрити/перезапустити Spotify, повторити попередні 2 сценарії й перевірити відновлення після зміни екрану
- [ ] «Знайди дорогу до [адреса]»: знайти адресу, короткий свайп угору, натиснути маршрут **Пішки**
- [ ] «Джарвіс таксі» та «постав будильник на 7:30» — команда передається на Pixel із підтвердженням; відповідь озвучена на Watch7
- [ ] JARVIS Finance: «витратив 150 готівка транспорт автобус»; підтвердження на Pixel, подальший запит про баланс; без дубльованих транзакцій
- [ ] Кнопка/тап обличчя мікрофона слухає до повної команди, другий запуск слухає теж; авто-свайпів вправо немає
- [ ] Перевірити, що застосунок залишається запущеним після озвучення й після переходу в Spotify/Maps

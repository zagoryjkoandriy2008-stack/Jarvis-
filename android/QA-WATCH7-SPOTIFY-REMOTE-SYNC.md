# JARVIS · Spotify Remote: Pixel → Galaxy Watch7

Стан: зміни в коді GitHub `main`. APK не збирати без команди користувача.

## Дані

- [ ] Pixel → Дімон → Spotify Remote має правильні рядки `Реп | https://open.spotify.com/playlist/...`, `Укр муз | ...`, `[Назва] | ...`.
- [ ] На Pixel натиснути «Зберегти Spotify»; усі коректні записи надсилаються через Wear OS Data Layer (`/jarvis/spotify-playlists/v1`).
- [ ] Після встановлення оновлення без повторного введення налаштувань відкрити Дімон на Pixel: наявний список автоматично повторно публікується.
- [ ] На Watch7 відкрити Дімон → ⋮ → «🎵 Spotify Remote — синхронізація». Повинно відображатися число та назви синхронізованих плейлистів.
- [ ] Перевірити «Реп», «Укр муз» і користувацьку назву. Client ID, Spotify токени чи паролі на годинник не переносяться.
- [ ] За відсутності з'єднання з Pixel годинник використовує збережену локальну копію. Якщо копії немає — повідомляє про необхідність синхронізації, а не шукає випадковий жанр.
- [ ] Після очищення списку на Pixel та збереження порожній список також синхронізується і затирає старі прив'язки на Watch7.
- [ ] Некоректний URI, дубль назви чи неприпустимий рядок не повинен частково змінити список.

## Відтворення на Watch7

- [ ] «Увімкни реп»: береться `spotify:playlist:...` з прив'язки `реп`; ніякого загального пошуку за словом «реп».
- [ ] «Увімкни українське»: URI плейлиста з прив'язки `укр муз`.
- [ ] «Увімкни плейлист [назва]»: URI за точною збереженою назвою; якщо такого URI немає — попередня навігація бібліотекою.
- [ ] Дімон пробує Spotify Content Link **лише на Watch7**, через `Intent.ACTION_VIEW` з `setPackage("com.spotify.music")`; URL не відкривається браузером і не відправляється на Pixel.
- [ ] Перед натисканням Play перевіряється, що Spotify відкрив сторінку потрібного плейлиста. Успішний Intent сам по собі не рахується успішним відтворенням.
- [ ] Якщо Spotify на Watch7 не підтримує Content Link або сторінка не підтвердилась за 6,5 с, Дімон пробує знайти плейлист за назвою у бібліотеці Watch7. Якщо назва прив'язки не збігається зі Spotify-назвою — потрібна перевірка користувачем.
- [ ] При Play підтверджено інтерфейсом Pause на потрібній сторінці. Після завершення/помилки Дімон повертається на передній план та готовий слухати.
- [ ] Команда «Увімкни пісню [назва]» та «Не та пісня» незмінна: лише довгі свайпи угору для відкриття пошуку, **без свайпів вправо**.
- [ ] На Pixel Spotify Remote продовжує працювати зі своїм Client ID, без зміни конфігурації.

## Непідтверджене на реальних пристроях

Чи обробляє конкретна версія Spotify для Galaxy Watch7 зовнішнє Content Link посилання — перевірити фізично. Android-компіляція й чисті Java тести цього не доводять. Якщо Spotify Wear не підтримує відкриття плейлиста за URI, працюватиме лише резервна навігація бібліотекою за назвою; у разі невідповідної назви сценарій завершиться повідомленням про помилку. Не обіцяти запуск без цього тесту.

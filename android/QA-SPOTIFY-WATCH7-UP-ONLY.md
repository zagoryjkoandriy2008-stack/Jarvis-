# Galaxy Watch7 — Spotify: пошук пісні тільки свайпом УГОРУ

Стан: зміни лише у вихідному коді `main`; APK із цією поведінкою ще не створено.

## «Увімкни пісню [назва]» / «Не та пісня»

- [ ] Команда на Watch7 відкриває Spotify саме на годиннику.
- [ ] Якщо іконку «Пошук» видно відразу, Джарвіс натискає її **без свайпу**.
- [ ] Якщо пошуку не видно — робить один **довгий свайп УГОРУ** (від 85% до 16% висоти екрана).
- [ ] Перевіряє іконку пошуку після кожного свайпу й не робить зайвого жесту, коли вона з'явилася.
- [ ] Якщо іконки немає, повторює **тільки УГОРУ**, загалом не більше 3 свайпів.
- [ ] Жодного свайпу ВПРАВО, ВЛІВО або ВНИЗ у сценарії пошуку пісні.
- [ ] Натискає пошук, вводить назву, Enter і натискає ПЕРШИЙ результат, незалежно від типу (пісня або плейлист).
- [ ] Якщо вибрав плейлист — переходить до Play; якщо звичайну пісню — не видає завершення жесту за підтвердження відтворення.
- [ ] «Не та пісня» переходить до наступного результату, а якщо повторно відкриває пошук — користується лише жестами УГОРУ.
- [ ] Після завершення Дімон повертається до прослуховування, Spotify не робить автоматичного свайпу вправо.

## Незмінні функції
- [ ] Команда «Увімкни плейлист [назва]» використовує стару навігацію бібліотекою, де можуть бути свайпи **вниз**; не плутати з пошуком пісні.
- [ ] Google Maps використовує власний короткий свайп угору перед «Пішки», незалежно від Spotify.
- [ ] Bolt, JARVIS Finance, Pixel Spotify та інші команди не змінено.

Результат автоматичної компіляції не є доказом фактичного натискання Spotify на годиннику.

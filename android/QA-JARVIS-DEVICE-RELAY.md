# JARVIS Pixel + Watch7 + Windows — міжпристроєвий чекліст

> Ці зміни — тільки у вихідному коді Android. APK **не створювати до окремої команди користувача**.

## А. Pixel
- [ ] Переконатися, що старі команди Spotify «увімкни пісню [назва]», «увімкни плейлист [назва]» не зіпсовано
- [ ] Головний екран: перемикач «🔗 Дозволити зв'язок JARVIS…» за замовчуванням **вимкнений**
- [ ] Плаваюче обличчя: «комп'ютер» показує 8-бітний монітор; «годинник» показує 8-бітний годинник; «телефон» повертає 8-бітний телефон у наявному режимі
- [ ] З Pixel сказати «комп'ютер» → «гучність 40»: змінюється тільки Windows; Pixel не виконує її повторно
- [ ] З Pixel сказати «годинник» → «увімкни плейлист [назва]»: запит іде через Cloudflare→Pixel→Wear OS
- [ ] «Телефон» активує старий режим Accessibility, без регресій, із підтвердженнями
- [ ] Фонова служба Pixel публікує постійне сповіщення; немає прихованого мікрофона
- [ ] З вимкненим Relay жодних дистанційних команд, навіть при ввімкненому мікрофоні
- [ ] Finance: локальний запис із Pixel і попередні записи залишилися незмінними

## Б. Galaxy Watch7
- [ ] Меню ⋮: «🔗 Керування пристроями» окремо включається, за замовчуванням вимкнене
- [ ] Внизу екрана видно компактну кнопку цілі ⌚/📱/🖥, натискання показує всі три варіанти
- [ ] «Телефон» викликає старий існуючий режим, «годинник» виходить із нього
- [ ] «Комп'ютер» обирає Windows через Pixel; «гучність 40» на Windows, а не на годиннику
- [ ] «Увімкни пісню» в локальному режимі Watch7 не передається до Pixel
- [ ] Дистанційна команда з Windows на Watch7 дозволена лише при **видимому** JARVIS і позитивному дозволі; при заблокованому/закритому застосунку повертається відмова
- [ ] Дистанційна Spotify команда Watch7 не робить зайвих свайпів вправо
- [ ] JARVIS Finance з Watch7 і далі записує через Pixel, не через Windows JSON

## В. Relay / цілісність
- [ ] Worker підтримує /device/v1/send/poll/ack/result/online лише з Bearer
- [ ] Команди живуть до 120 секунд; після цього не виконуються
- [ ] Різні ID не змішуються; один ID не виконується двічі навіть після повторної доставки
- [ ] Відповідь досягла того самого джерела, а не іншого пристрою
- [ ] Відхилено довільний shell, PIN/паролі, несанкціоновані Telegram-повідомлення
- [ ] Відключення Wear/Pixel/Worker не робить вигляд, що команда виконана
- [ ] Запит фінансового звіту Windows читає **справжню базу Pixel**, не копію
- [ ] Після перезапуску кожен пристрій не вмикає приховане дистанційне керування автоматично без дозволу

**Не готово до claim “усі команди”:** Windows наразі має тільки підтримані локальні дії, а дистанційний канал — локальні allowlist-запити. Синхронізація офлайн-баз Finance/notes/macros та попристроєва авторизація окремі наступні етапи. Фізичні тести ще не виконані.

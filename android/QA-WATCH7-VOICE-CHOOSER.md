# Galaxy Watch7 — вибір голосу Джарвіса

Статус: зміни у вихідному коді, APK не збирався без прямої команди.

## Інтерфейс на годиннику
- [ ] Відкрити Дімона на Galaxy Watch7: головний екран лишається обличчям без зайвих кнопок.
- [ ] Натиснути **⋮** угорі праворуч → **🔊 Вибрати голос Watch7**.
- [ ] Є чотири дії: «Вибрати голос Android», «Тембр», «Прослухати», «Додати голоси в Wear OS».
- [ ] «Вибрати голос» показує системний голос Android і **всі українські голоси, що їх повернув Android TTS**. Мережеві підписані «потрібен інтернет».
- [ ] При відсутності встановлених українських голосів список не порожній: залишено системний голос; є пояснення та посилання на налаштування Android.
- [ ] За запуску TTS до завершення ініціалізації екран не падає, повідомляє про підключення, дозволяє перейти до налаштувань.
- [ ] Вибрати другий встановлений голос, якщо він є; відтворити зразок.
- [ ] «Тембр» має чесні варіанти *нижчий / звичайний / вищий* — це той самий синтезатор, а не вигадані інші голоси.
- [ ] Після повторного запуску Дімона встановлений голос і тембр залишилися.
- [ ] Видалити/змінити рушій TTS — вибір повинен безпечно повернутися до системного голосу.
- [ ] «Голосові відповіді» вимикаються й вмикаються, включно з голосовими командами, без аварії через відсутній checkbox.
- [ ] Команди «Голос Дмитро/Лада» не видають недоступну модель за встановлену — відкривається список реальних голосів.
- [ ] Зміни голосу Watch7 **не змінюють** профіль Дмитро/Лада/Supertonic на Pixel.

## Збереження попередньої поведінки
- [ ] Spotify Watch7: пошук пісні — лише свайп угору, ніколи вправо.
- [ ] Google Maps Watch7: короткий свайп угору та натискання «Пішки».
- [ ] Мікрофон, відповідь голосом, Finance і команди через Pixel не постраждали.

Не плутати *успішну компіляцію* з тестуванням реального набору голосів Wear OS. Android TTS може надати лише один український голос або вимагати встановлення мовного пакета.

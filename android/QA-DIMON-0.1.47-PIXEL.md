# Дімон 0.1.47 — Google Pixel: апаратний чекліст

> Чисті автоматичні тести означають відповідність кодових контрактів, а не реальні Android-жести. Тестувати з увімкненою службою доступності та Spotify, Bolt, Maps.

- [ ] Встановити 0.1.47 поверх 0.1.46, переконатися, що дані й налаштування збережено
- [ ] Перевірити дозволи мікрофона, доступності, сповіщення, роботу у фоні й увімкнення через подвійний тап
- [ ] Перемкнути голос Дімона (Дмитро, Лада, Supertonic, якщо моделі/голоси реально доступні); прослухати й перезапустити
- [ ] «Увімкни пісню [укр/рос/англ назва]»: Spotify → вкладка пошуку → редактор → введення → Enter → реальний перший результат; перевірити звук
- [ ] «Інша пісня»/«Не та пісня»: кожне наступне викликання переходить на наступний результат, не повторює перший
- [ ] Якщо першим результатом виявився плейлист, натискання має відкрити його та ввімкнути Play
- [ ] «Увімкни плейлист [назва]», «увімкни реп»: відтворення, а не тільки відкриття; список синхронізованих плейлистів Spotify Remote видимий у параметрах
- [ ] Повторити команди Spotify з уже відкритим пошуком, відкритим плейлистом і під час завантаження інтерфейсу
- [ ] «Джарвіс таксі [адреса]»: Bolt повністю завантажується, за потреби повертається назад, «Рушаймо» → «Місце висадки» → Enter → перша підказка адреси
- [ ] Команди «телефон», «напиши ...», «натисни ...», свайпи й керування ліхтариком/гучністю
- [ ] Команди з годинника виконуються на правильному пристрої, відповідь повертається без аварії
- [ ] JARVIS Finance: записи витрат і доходів, перегляд звітів/бюджетів, відновлення після рестарту без повторного створення
- [ ] Оповіщення внизу екрана з'являються на етапах роботи, зависання та виходи з режиму не гублять стан
